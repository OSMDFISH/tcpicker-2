# TCPicker V2 Cloud Deploy

## Streamlit Cloud deployment

1. Create a free GitHub repository.
2. Upload these files:
   - `streamlit_app.py`
   - `requirements.txt`
   - `README.md`
3. Go to Streamlit Cloud.
4. Click **New app**.
5. Select your GitHub repo.
6. Main file path:
   `streamlit_app.py`
7. Click **Deploy**.

After deployment, open the Streamlit app link on your iPad Safari.
